Ini adalah repository untuk distribusi aplikasi kita, diakses bagi customer kita untuk di-download.

## Microsoft Store (MSIX)

MSIX hanya dibuild untuk tag stabil `zerix-vX.Y.Z` (tanpa suffix). Hasilnya ada di Actions artifact `zerix-msix-<tag>` (disimpan 30 hari), di-upload manual ke Partner Center, dan tidak masuk GitHub Release publik. Kegagalan job MSIX tidak memblokir release exe/dmg.
